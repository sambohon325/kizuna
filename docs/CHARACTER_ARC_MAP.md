# Character Arc Map

The Writer's Room Story Map can switch between production coverage and character arcs.

For each character, the arc view combines:

- the saved emotional beginning, turning point, and ending from Character Studio;
- planned shot appearances across story beats;
- suggested arc placement at the first, middle, and final appearance;
- shared appearances with defined character relationships; and
- clear warnings when the profile or screen coverage is incomplete.

Suggested placements are guidance, not completion signals. A creator can open any beat in the production map or jump directly to the character's story profile to revise the source material.
