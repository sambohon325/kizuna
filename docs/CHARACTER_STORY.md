# Character story development

Character Studio separates three related crafts:

- **Identity** defines the character's story function, conscious want, underlying need, and central contradiction.
- **Story & arc** records history, a formative event, secret, fear, misbelief, personal stakes, and the character's beginning, turning point, and ending state.
- **Visual model** defines appearance, wardrobe, palette, consistency locks, and reference-sheet generation.

Story profiles are versioned whenever they are saved. Existing character records remain compatible because story development is stored separately from the core identity and visual model.

Relationships connect two characters in the same production. Each connection records its type, public dynamic, private truth, dramatic tension, and relationship arc. Saving the same target again updates the existing connection instead of creating duplicates. Removing a relationship does not delete either character.
