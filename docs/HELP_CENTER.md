# Kizuna Help Center

The Kizuna Help Center combines three forms of guidance without mixing their authority:

- the studio tour introduces the interface;
- task articles provide step-by-step learning paths; and
- the Help Agent answers natural-language questions from the published Kizuna manuals.

## Grounded-answer boundary

The Help Agent is extractive. It searches a curated allowlist of published documents, selects relevant passages, and returns source links. It does not use project data, unpublished roadmap notes, support tickets, administrator records, or general model knowledge. If the approved library does not contain a relevant answer, it says so instead of inventing instructions.

## Asking a useful question

Name the task and workspace when possible. For example:

- How do I change a short film into a series?
- Where do I approve a character model sheet?
- How do I create a review animatic before a final render?
- How do I pause one Hive computer at night?
- What records do I need for licensed music?

The answer includes up to three source sections. Open a source when you need the full explanation or specialist detail.

## When to contact support

Use support rather than the Help Agent for account access, billing, suspicious activity, security, legal notices, data deletion, missing production data, or a product failure not resolved by the manual. Never include passwords, API keys, or confidential media in a support ticket.

## Updating the knowledge base

Product guidance should be updated in the relevant Markdown manual and reviewed with the feature change. A document becomes visible to the Help Agent only when it is explicitly added to the published-document allowlist. This prevents drafts and internal notes from becoming customer instructions accidentally.
