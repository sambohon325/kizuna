# Production scope

Production scope is the release contract shared by the entire Kizuna workflow. It records:

- distribution channel;
- one-off, trailer, feature-film, ongoing-series, or limited-series format;
- landscape, vertical, square, classic, or cinematic aspect ratio;
- target runtime per release;
- installment and season counts; and
- optional release notes.

The New Production flow captures this before story development. Scope remains editable from production cards and the Writer's Room.

Changing scope preserves existing work. If an outline already exists, Kizuna updates its format and runtime targets and marks it **Outline needs adaptation**. The creator can then revise or regenerate the story deliberately. Timeline dimensions follow the selected frame, and 1080p/4K mastering preserves landscape, vertical, square, and cinematic aspect ratios.

The built-in story planner changes its dramatic spine by target: hook-first short-form, trailer structure, episodic structure, a standard one-off arc, or a twelve-beat feature spine.
